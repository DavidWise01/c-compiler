The Program

born · what it does · the line

Born
Bell Labs · 1972–73

Dennis Ritchie created C (from B, from BCPL) and its compiler; Unix was then rewritten in it, an act that made the OS portable.

What it does
compile to the metal

Translate human-readable C into the machine's own instructions — close enough to the hardware to write an operating system, portable enough to move it.

The line
BCPL → B → C → everything

C begat C++, Objective-C, and the syntax of half the languages alive; cc begat gcc, clang, and every modern compiler.
